# Physics-Informed-Deep-Learning-Forecasting-Model-Code
IUH-PIGRU, IUH-PILSTM, IUH-PITCN, GRU, LSTM, and TCN model
All Python files can be run directly after modifying the parameters.
“Transfer_train.py” and "Transfer_train2.py" are for transfer learning of IUH-based models (IUH-PIGRU, IUH-PILSTM) and pure models(GRU, LSTM).
